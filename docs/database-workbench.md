# 数据库工作区设计

## 方案选择

| 方案 | 布局 | 取舍 |
| --- | --- | --- |
| A（采用） | 左侧上下分区，中间数据页签，右侧结构 | 连接与对象同时可见；垂直分隔可拖动，适合日常浏览 |
| B | 连接/对象用页签切换 | 窄屏节省空间，但操作中频繁切换且丢失连接上下文 |
| C | 独立对象窗口 | 多屏灵活，但增加窗口管理与焦点成本 |

## 交互规则

- 上部标题 Databases / 数据库；标题右侧切换按分组、环境、创建日期、最近使用日期。移除侧栏无效放大项，不提供关闭按钮；更多菜单提供“重置上下比例”。
- 新建连接、搜索、分组依次排列。搜索主机、库名、环境、驱动、连接名与分组，不隐式连接远程服务器。
- 分组/环境模式显示最近成功打开的 5 个连接，固定在最前；日期模式不显示最近。历史连接缺少创建时间时归入“日期未知”。
- 创建空分类可在新建连接表单中选择；分组与环境分别保存排序。分类折叠与上下分隔比例写入现有导航存储，重启后恢复。
- 连接名称必填且不自动生成；数据库目标必填（SQLite 为文件，Redis 为逻辑库编号）。原有名称保留，旧配置缺少数据库目标时提示补全，检测可先获取库名后选择。
- 连接项第一行显示品牌图标和连接名，第二行用灰色小字显示 `host:port/database`（SQLite 显示文件名）。绿色/灰色/红色圆点表示已连接/未连接/失败，连接中显示转圈；已连接提供断开，连接中提供取消。
- 检测后的数据库名下拉内置筛选框，按名称包含匹配且不区分大小写；搜索不改动表单值，选择后回填，仍允许手工输入。参数变化使旧检测结果失效。
- 下部标题 Objects / 库对象；数据库选择器切换上下文，刷新、导入 SQL、导出已加载结构、新建对象均有明确作用范围。“新建数据库”收进标题右侧＋菜单，仅支持建库的类型显示，取消下方整行按钮。
- 对象根节点按驱动/版本能力呈现；搜索覆盖对象名称、Schema、父表名及已读取的注释。旧版 MySQL 不虚构不存在的能力，Redis 使用原 Key 浏览器。
- 表/视图双击在中间打开数据页，重复打开复用实体。列双击打开编辑表单，保存后显示可复制的 SQL 预览，执行前再确认目标及风险。
- 仅表名右键提供数据、Note、ER、结构、重命名、复制、删除、比较、导入和导出；每张表独立菜单状态，其他节点不展示这份菜单。表内分类显示折叠箭头、图标和文字，以独立外层容器实现逐级缩进。第一次复制 DDL/重命名会自动加载结构后继续，无需第二次点击。

## 执行与容量边界

- 共用后台会话、请求编号、超时及断开机制。关闭页签不等于断开连接。
- 100 行分页，额外读取一行判断下一页，不执行昂贵的全表 COUNT。存在主键时按主键排序；没有主键时提示顺序不保证。翻页不是固定快照。
- 目录每类最多 500 项，超限提示；数据预览最多 768 KiB、512 列，超限报错而不静默截断字段。
- NULL 与空字符串独立存储。CSV 导出范围为当前页；导入最多 100 行 / 48 KB，列名必须匹配，先生成 SQL 再执行。`\N` 表示 NULL，空字段为空字符串，文本开头的反斜杠需转义。二进制值以十六进制展示，此 CSV 功能不是二进制备份工具。
- 比较为同一 Schema 两表的当前页比较，按行多重集合计数，明确不等于全表一致性校验。
- Note 是当前表的查询说明与分析笔记，可保存 Markdown；不宣称已接入整个 Notebook 的持久化执行引擎。ER 展示当前表与声明外键关系，不推断未声明的关系。
- MySQL 列修改从 SHOW CREATE 保留完整尾部属性；PostgreSQL 使用 ALTER COLUMN / RENAME / COMMENT；SQLite 只开放安全重命名，不自动重建表。ClickHouse 每次修改一个属性。
- 结构预览绑定连接代次，执行前重新读取 DDL 校验。DDL 可能隐式提交，超时不自动重试，需重新确认服务端结果。
- PostgreSQL 复制 DDL 为逻辑列、默认值和约束定义，并明确标注不含存储、分区、所有权设置；不替代 pg_dump。
- SQL 文件预览最多 60 KB。兼容驱动与 ClickHouse 的多语句能力受服务端协议限制，不绕过限制或宣称事务原子性。

## 验证

服务层测试覆盖 SQLite 分页、NULL/空串、结构变化拒绝执行、CSV 特殊字符往返、MySQL 列定义属性保留及能力列表。真实适配器验证沿用隔离脚本，不访问用户现有数据库。

### 本次验证记录

- `cargo test --workspace --locked -j 1`：73 项测试通过；最终修改后再次运行 4 项 workbench 定向测试。
- `cargo clippy --workspace --all-targets --locked -j 1 -- -D warnings`、格式检查与桌面/兼容助手构建通过。
- 真实隔离实例：MySQL 4.0.27、4.1.22、5.1.73、8.0.30，PostgreSQL 16.4，SQLite 3.46。覆盖对象目录、结构、三页共 205 行、NULL/空串、列重命名后默认值保留。Redis 5.0.14.1 原有 Key 浏览协议回归通过。
- ClickHouse 仅通过本地 HTTP 协议模拟（目录、结构、分页与既有接口），尚无真实服务端验收。
- `python scripts/verify-database-workbench-ui.py`：原生窗口双击开表、翻页、列编辑、SQL 预览不写入、明确执行后生效、分组/环境/日期切换、拖动排序、分隔比例持久化及重启恢复通过。脚本仅控制自建临时 SQLite / 便携程序，诊断上报与 AI 自动连接均关闭；截图保存在本次 `target/workbench-preview-*` 目录。

连接 SQLite 存储、时间字段、密码沿用和统一反馈规则见 [连接存储与交互设计](connection-storage-and-feedback.md)。

连接项单行显示驱动图标、连接名和灰色地址，右侧保留状态及断开按钮；名称与地址分别截断，悬停显示完整信息。最近列表与普通分组共用样式。

点击连接时编辑配置和库对象使用同一目标；未连接目标清空上一连接的对象并提示双击连接。切换会废弃旧元数据请求 ID，迟到结果不再覆盖新目标；后台连接成功只刷新仍被选中的连接。正在执行的数据查询/写入需完成或取消后再切换，连接会话不会因浏览其他连接而断开。

连接联动验证：两个对象不同的隔离 SQLite 库间切换、未连接 Redis 配置切换均正确更新库名与对象内容，原连接会话保留；编译和 Clippy 通过。

数据库连接的自定义分类现统一称为“项目”：侧栏按项目组织，连接表单使用项目字段，可选择已有项目或新建项目；空值显示“未指定项目”。已有配置的 `group` 字段、分类内容、排序与折叠存储键保持兼容。

# 数据工作台设计与实现

## 方案选择

| 方案 | 设计 | 取舍 |
| --- | --- | --- |
| A（采用） | 虚拟表格、紧凑工具栏、右侧检查器，先暂存再提交 | 可复用 GPUI Table，适合大表浏览及批量修改 |
| B | 以单行弹窗为主要编辑方式 | 简单，但多行操作繁琐 |
| C | 完整电子表格式编辑器 | 功能密度高，状态与维护成本更大 |

连接选择页支持图标/列表两种视图，筛选在本地执行，不发起数据库连接。名称生成仅由图标点击触发。

连接名比较：①库名→库名@主机短标识→序号（采用，短且可辨认）；②库名@环境（适合部署环境，但同环境仍可能重名）；③库名-随机短码（唯一性好，但难记）。当前生成会排除正在编辑的连接，大小写不敏感地检查已有名称。

列详情比较：①单行 tooltip（紧凑但信息少）；②多行信息卡＋菜单复制（采用，展示名称、类型、描述与归属表）；③点击展开元数据弹层（信息多但多一步操作）。表头低频操作统一放在下拉菜单。

## 数据与交互

- 复用 GPUI Table 的行列虚拟化、双向滚动条及固定列，行号固定在最左。单元格预览最多 256 字符；原始值保留用于复制和检查器。
- 表头显示主键、数字、日期时间或字符标识，支持复制列名、服务端升降序、类型安全的筛选条件和右侧表结构。
- 表结构和检查器复用右侧固定面板；支持表格/TXT，长值在下方多行查看器中展示，复制完整原始内容。
- 鼠标选择和方向键移动更新同一个单元格坐标，状态栏可开关行列高亮。
- 行菜单支持单元格、行复制和 CSV/JSON/SQL/Markdown/TXT 高级复制；删除先标记，再在提交时确认 SQL。
- 新增与复制新增进入暂存区，复制新增省略主键，让数据库默认值或用户输入决定新键。默认值、NULL 与空字符串需要明确区分。
- 回滚仅丢弃未提交的修改，不撤销数据库中已经提交的数据。翻页、排序、筛选与刷新不得静默丢弃修改。
- 总行数按用户点击统计，避免打开大表就执行 COUNT(*)。状态栏显示本页数量、查询耗时、当前坐标及待提交数量。

## 分页与提交

- MySQL、PostgreSQL、SQLite 默认使用可靠主键（支持复合主键）作升序游标。通过已访问页的游标历史向前翻页。
- MySQL 4.0 因字符集表达式兼容性回退偏移分页；无主键、非关系型适配或显式排序时也回退 LIMIT/OFFSET；筛选与排序字段须匹配真实列，值按适配器转义，不接受拼接的 SQL 条件。
- 总数与分页都受既有连接取消和响应体上限约束；浏览不提供跨页快照保证。
- 无主键表仍可新增；修改/删除已有行要求可可靠定位的主键。二进制、浮点主键不用于游标；二进制列不支持文本编辑；含二进制值的行不生成可能失真的 SQL 复制，CSV/JSON/TXT 等保留预览文本，不作为二进制备份。
- 事务编辑支持 SQLite、PostgreSQL、MySQL InnoDB；只读连接和不支持事务的表不进行批量写入。
- 提交前冻结 SQL、目标及修改列表；服务端验证表结构，事务内锁定/核对原始行，再执行修改。任何失败回滚全部修改；回滚状态未知时提示重新连接核对。
- 保留已有行数、列数和响应体限制，不为了展示大数据而一次加载全表。

## 消息

右上角消息限制显示高度并支持滚动。失败消息提供复制按钮，复制完整消息；常规成功消息仍自动消失。

## 验证范围

SQLite 实库与原生窗口覆盖：暂存不写入、回滚、取消确认不写入、确认后更新、新增默认值、复制当前行新增、复合主键游标、前后翻页、排序筛选、总数统计、行复制转义、事务失败回滚和并发冲突。MySQL/PostgreSQL 适配逻辑已编译；本轮尚未进行这两类真实服务端的完整编辑验收。

验证结果：90 项工作区测试通过；原生 SQLite 窗口验证表头提示与菜单、双向滚动、固定行号、高亮、统计、游标前后翻页、排序/筛选、暂存/回滚/确认提交、新增默认值、复制新增、长值检查器和表结构 TXT/表格切换。连接类型两种视图、筛选及库名前缀生成已验证。

补充原生验证：删除行确认后生效，无主键表可使用默认值新增；未修改单元格不会产生待提交记录。错误通知复制内容与完整原文一致。

## 表格操作精简

比较三种方案：双排序按钮常驻直观但占宽；悬停显示最简但发现性较弱；采用单按钮循环升序、降序、默认排序，常驻表头并显示当前箭头。复制列名移入下拉菜单，与筛选、查看表结构并列。

类型标识复用主键钥匙、123、日期图标与 ABC，并针对明暗主题赋予不同颜色；文字与形状仍可独立区分类型。表格对应轴溢出时滚动条常显，固定行号不随横向滚动。底部空心十字切换行列高亮，旁边调色板支持预设和十六进制颜色，改色后可恢复默认；关闭高亮仍保留当前单元格边框。颜色当前随表页签保留，不增加全局设置项。刷新操作统一使用双循环箭头资源。

补充样式验收：原生窗口验证排序三态切换、菜单入口、预设蓝色高亮、恢复默认、关闭高亮、横纵滚动条拖动及无溢出时隐藏。列名复制本轮自动读取受系统剪贴板访问拒绝影响，未完成剪贴板断言。

## 连接选择与库摘要

采用单行合并摘要，而非独立状态徽标或底部统计。单击连接仅切换库对象，不改变中间页签或表单草稿；双击连接，右键“编辑连接”才进入配置。离线显示“account_center（未连接）”并隐藏空分类；读取中显示加载状态；连接成功后只显示库名，不再在库名旁重复统计表和视图；分类节点自身数量仍保留。原有兼容性或截断提示仍保留。

连接交互已通过隔离 SQLite 原生窗口验证：单击不新增配置页、双击连接不打开配置、离线切换与重新选中、右键编辑正常打开；库摘要准确显示 2 表 · 1 视图。

## 底部单行工具条与主题色

方案 A（采用）：常用动作、分页、高亮及统计整合到 32px 底栏，低频动作收进更多；方案 B 全部图标常驻，在窄面板容易拥挤；方案 C 全部动作放右键，发现性较弱。数据页移除重复的顶部标题/按钮及多行状态栏，工具条按操作、分页、高亮与统计分组，右侧突出本页行数、按需总数和查询耗时。编辑、复制新增及导出当前页直接以图标显示。筛选条件与排序显示在表格顶部，分别清除；坐标、待提交数量和分页方式可悬停查看，待提交数量非零时同时常驻提示。极窄面板工具条保持单行并允许横向滚动。

高亮默认色：浅色主题使用暖黄色，深色主题使用低饱和蓝灰色；按不同透明度区分关联行列与当前单元格，保留单元格边框。未自定义时随主题实时变化，手动选色后保持所选色，恢复默认重新跟随主题。复用既有调色板和暂存/提交逻辑，不增加全局设置项。

底栏原生验收：单行布局、总数统计、翻页与更多菜单正常；默认高亮随明暗主题变化，自定义蓝色跨主题保留，恢复默认后浅色主题回到暖黄。工作区 90 项测试、Clippy 和格式检查通过。

## 可调分页与常用按钮

比较三种分页方案：A 手动总数＋可调页大小（采用）；B 自动统计总数，可能增加大表等待；C 仅上一页/下一页，无法满足尾页和页码跳转。底栏直接显示复制当前行新增、编辑、导出图标；分页为每页大小、首页、上一页、页码输入、下一页、尾页。大小默认 200，支持 1–1000，输入后回车应用并回到首页。总行数由独立 Σ 按钮手动计算（遵循当前筛选），未知时尾页不可用并提供提示，统计不会自动跳页。筛选变化、提交和显式刷新使旧总数失效。

连续翻页优先主键游标；跳页、尾页及缺少游标的回退查询采用 OFFSET，仍保留 1000 万偏移上限与 768 KiB 响应体保护。页大小变化清空旧游标；按页位置保存游标，跳页后不会错配上一页。行数区固定可见，窄窗口的操作区可横向滚动，保持单行。统计结果不承诺并发修改下的快照一致性。

分页验证：91 项工作区测试通过；隔离 SQLite 原生窗口已验证默认 200、输入 50、手动统计 205、尾页 5 行、上一页、输入页码跳转、复制新增暂存，以及越界页统计后返回尾页。输入 1001 被拒绝且保留原页大小。行数显示采用“本页行数 / 总行数”，未知总数用 —，悬停给出完整含义。

最终原生复验：页码输入保持焦点时，尾页/首页会立即更新数字；空页不残留纵向滚动条。导出图标可打开保存窗口，取消后不写文件。主程序和 MySQL 兼容辅助程序均已重新构建。

## 顶部筛选与按需编辑

采用顶部多条件列表方案：比较符号为 =、≠、>、≥、<、≤，下拉菜单同时显示中文含义；文本默认“包含”。列头筛选展开对应字段的顶部编辑区，选择字段/符号/值后回车或点击应用才查询。顶部摘要来自已完成查询，编辑区显示未应用修改或加载状态；失败保留旧条件与数据。NULL 判断隐藏值输入，收起编辑区不会取消已应用条件，清除筛选与清除排序独立。支持最多 20 条条件，统一切换 AND（全部满足）或 OR（任一满足）；每行可更换字段和删除，列头新增筛选保留已有条件，暂不支持混合嵌套组。

日期、时间分别输入；日期旁提供日历，时间字段保留小数秒与时区。“当前时间”快速填入当前时刻，已有时区会保留并换算为相同瞬间。选择日历仅替换日期部分，保留小数秒、时区和原分隔符；未改动的特殊旧日期不被自动格式化。NULL、空字符串、DEFAULT 明确区分。单元格编辑使用“设为 NULL / 恢复原值 / 复制 WHERE 条件”工具栏；已有行恢复数据库读取值，新行恢复打开编辑器时的值，DEFAULT 仅对新行提供。WHERE 使用当前编辑值，NULL 生成 IS NULL，只复制、不执行。筛选和单元格编辑共用同一个值输入组件。

新增、复制新增、编辑单元格相邻，提交/撤销单独一组。默认只浏览，不因输入普通字符写入；双击/F2 打开编辑器，新增/复制新增定位至新行的首个非主键列。实际修改后显示“编辑中 · 待提交 N”，提交/撤销后自动恢复浏览。Ctrl+C 在表格焦点复制当前单元格；编辑输入框保留其原生文字选择/复制语义，Esc 沿用对话框取消且不应用值。连接只读、事务预览与二次确认保护保持有效。

顶部筛选验收：92 项工作区测试通过；SQLite 原生窗口验证 ≥ 条件、未应用草稿、收起保留条件、清除筛选保留排序、日期日历与手动输入同步、NULL 隐藏输入、回车应用、日期暂存与撤销。Ctrl+C 完整单元格及编辑框选中文字均与实际剪贴板内容匹配；F2、Esc 与默认浏览行为已验证。日期调整后小数秒及时区保留，暂存期间数据库值未改变。

## 条件组合设计取舍

采用平铺条件＋统一 AND/OR，减少括号优先级的理解成本；嵌套条件组表达力更强但操作更重，原始 SQL 条件输入留给专业查询场景。查询、游标分页和手动统计共用条件编译器，OR 组整体加括号后再与主键游标组合，禁止把条件组直接展开到分页 AND 之外。保留单条件协议兼容，限制条件数和生成语句长度。

多条件与编辑工具栏验证：95 项工作区测试串行通过，覆盖 OR 与主键游标的括号语义、AND/OR 统计、条件上限、WHERE 转义、NULL 及当前时间的精度/时区。首次并行运行中既有 Windows 凭据清理用例失败，单独及串行全量复验通过，未改动凭据模块。原生 SQLite 窗口验证 AND/OR 切换、分页与统计一致、删除条件保留其他值；日期/时间独立修改、日历、当前时间、恢复原值、普通值/NULL 的 WHERE 剪贴板匹配均通过。DATE、TIME、DATETIME 均已验证，暂存和恢复不会提前写入数据库。

## 统计与滚动优化

总行数仍手动统计；加载状态放在底部计数图标右侧，不为统计追加文本行，也不显示虚构百分比。移除仅表示浏览/编辑状态的眼睛图标。

复制单元格 WHERE 按列类型生成：普通 MySQL 文本使用带引号的可读字面量，数字直接显示；单引号转义，反斜杠和控制字符保留不依赖 sql_mode 的安全表达式，二进制预览仍不允许生成无损条件。执行中的 SQL 继续复用原有安全编码。

保留双向虚拟表格。推荐方案 A 已采用：缓存最多 4096 个单元格的 256 字符显示预览，页面数据或编辑快照改变时重建；完整值不截断，复制/编辑不使用预览缓存。表头说明在悬停时才格式化，元数据共享。方案 B 为拖动中减少装饰（会降低反馈完整性）；方案 C 为自绘表格（成本高，需重新验证编辑和可访问性）。当前未声明特定帧率或性能倍数。

验证：WHERE 回归测试及 Clippy 通过；原生窗口以隔离 SQLite 锁等待验证计数加载时仍保持单行，释放锁后显示总数；1000 行、52 列测试横向/纵向拖动。未进行前后帧率基准对比。

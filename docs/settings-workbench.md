# 设置与常用操作

采用 A：左侧分类、右侧精简列表、复杂配置弹窗。B（全部平铺长表单）查找成本高；C（卡片仪表盘）占用空间较大。

- 导入连接逐项勾选，提供全选/全不选，默认全选；只校验和保存选中项。DBeaver JSON 与 ZIP/DBP 项目归档复用内容识别，仅解析 data-sources.json，不导入凭据。
- 输出标题可点击切换底部布局；Ctrl+J 同样切换。Ctrl+B 切换左侧栏，Ctrl+, 打开设置。表格保留 Ctrl+C 复制、F2 编辑。
- 连接名生成使用编号与星芒图标，避免与刷新混淆。
- 通用默认字号 14px，已有字号不覆盖；字体与字号同排，字体列表读取本机全部已安装字体并支持搜索，也可自定义输入；SQL/中文实时预览位于下方。
- 数据库分类分查询、SQL、驱动三个子页。每页行数默认 200，设置用于新打开的表；已有表沿用当前分页设置。SQL 自动换行默认开启并同步已打开的 SQL 编辑器。
- Notebook SQL 可选择 Ctrl+Enter（默认）或 Enter 执行；风险写入始终需要预览与二次确认。通用项增加 Note 临时目录与自动保存，详见 [Note 工作台](note-workbench.md)。
- 驱动按数据库类型列表显示，内置适配器无需下载，MySQL 旧版兼容驱动在弹窗管理。
- Codex/Claude 平铺列表显示实际连接状态，配置弹窗复用现有连接与自动保存流程。扩展智能体、AI 提供商属于配置登记，明确显示尚未接入会话，不能将登记状态称为连接成功。
- 设置沿用 settings.db 和自动保存流程；对话框关闭不等于撤销已自动保存的修改。

## 验证

103 项工作区测试通过，Clippy 零警告。Windows 原生窗口验证了输出展开、Ctrl+J/Ctrl+,、字体选择和 18px 预览及持久化、默认分页 500 行应用于新表、智能体/提供商弹窗，以及 DBP 识别两条后仅勾选导入一条（未选必填缺失项不影响导入）。设置渲染按分类拆分，修复调试版打开设置时的栈溢出；最终提供商精简弹窗已验证。此处为原有设置验收记录；后续 Note 执行与存储设置的验证见 Note 工作台文档。提供商/扩展配置不等于会话接通。

## 导入时补全数据库

每个连接项仅选择一个数据库，保留手动填写。检测前校验用户名，凭据弹窗的密码仅用于临时会话，不保存；TLS 降级须确认，只有检测成功的模式会随最终导入保存。检测可取消，关闭预览释放临时会话；输入变化后旧结果不回填。发现一个库自动填入，多个库提供可搜索下拉框；无列表权限或查询失败时仍允许手动输入，错误提示可复制。SQLite 保持本地文件目标。

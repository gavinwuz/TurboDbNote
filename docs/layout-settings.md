# 布局与设置中心设计与验收

**目标：** 统一图标文字交互、可关闭页签、分组设置、SQLite 配置与帮助更新入口。

**方案比较：** 工作台页签式保留编辑上下文且适合复杂表单，独立窗口式空间大但切换成本高，抽屉式紧凑但不适合模型高级参数。采用工作台页签式。

**架构：** 保留 GPUI Dock 与已有 Codex/Claude 会话。设置分为通用、智能体和提供商；SQLite 使用事务持久化，首次导入旧 JSON。语言包独立 JSON，内置中文/英文并允许外部覆盖。模型目录和更新检查在后台进行。

**技术：** Rust / GPUI Component 0.5.1 / SQLite / HTTP。

## 实施步骤
1. preferences.rs：新增通用、提供商、扩展智能体数据；SQLite schema 与旧文件迁移；测试重复保存、迁移与错误。
2. 新增语言包模块与资源，应用字体字号和语言选择。
3. settings.rs 与设置表单：分组导航、提供商/协议选择、模型目录、高级 JSON 参数、智能体安装入口。
4. 页签统一标题与关闭菜单；设置关闭仍需处理未保存编辑；Notebook 实体保持存活以支持重新打开。
5. workspace.rs：图标文字按钮、关于、GitHub、后台检查稳定发布版本。
6. 格式、测试、编译、Clippy；双语 README 与变更日志；记录实际验证范围。

## 交互规范
- 4/8/12/16/24px 间距，导航约 160px，表单最大宽度 760px，长内容滚动。
- 使用主题 foreground/muted/border 颜色，选中导航高亮；按钮保留键盘焦点。
- 中文优先系统 UI 字体，英文可用 Segoe UI，编辑可用 Cascadia Code。字号支持 12–24px。
- 网络任务提供加载、空结果、错误和重试；不在切换选项时自动发送 API Key。
- 扩展安装采用显式官方安装入口及本地配置，不静默执行下载脚本。

## 验收
验证左右页签关闭边界、脏设置关闭、重开后编辑保留、SQLite 首次迁移/重复保存、语言包回退、模型目录三种协议及错误、更新 SemVer 比较；原有聊天测试继续通过。

## 用户补充：自动保存
移除所有设置保存按钮；停止修改 600ms 后防抖保存。自动保存不建立智能体连接、不请求推理。页签和窗口关闭前立即刷新；验证失败或写入失败保留草稿，显示重试/放弃/继续编辑。全局外观变更也自动保存。扩展智能体目前提供独立安装入口与配置登记，内置聊天仍为 Codex/Claude。

## 用户确认的图标规则
标题栏操作（包括最大化、最小化、关闭）与最左侧 48px 导航栏（项目、连接、设置、帮助）仅显示图标并保留悬停提示。内容区按钮、设置分类显示图标＋文字。编辑页签显示图标＋标题＋关闭图标；右侧固定工具页签只显示图标＋标题。

## 方案取舍

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 工作台页签＋左分类导航 | 保留编辑实体、适配长表单、易于扩展 | 需管理关闭和辅助区域恢复 | 采用 |
| 独立设置窗口 | 表单空间独立 | 频繁切换上下文、多窗口状态复杂 | 不采用 |
| 侧边抽屉 | 轻量快速 | 模型配置字段多，窄屏拥挤 | 不采用 |

## 实现边界
- SQLite 事务保存完整设置文档，旧 JSON 只读迁移并保留。较新 schema 拒绝降级写入。
- 语言包为独立 JSON；同 ID 外部包合并覆盖，缺失键回退同语言内置包、内置英文。原有示例笔记内容不翻译。
- API 提供商支持配置与按需模型列表获取，三种 API 模式均有本机 HTTP 测试。尚未替换现有 CLI 聊天传输。
- Codex/Claude 保留现有聊天；OpenClaw 和扩展智能体可登记独立程序、目录、安装链接，尚未接入内置聊天。
- 关于展示版本及发布日期状态；0.1.0 是未发布预览版，不填虚构发布日期。
- API Key 在控件中遮罩，但数据库未加密。网络不跟随重定向，错误不输出密钥或响应正文。

- `cargo check --locked --workspace --all-targets`、Clippy `-D warnings` 与原生 debug 构建通过。
- 原生窗口验证：中英文设置、图标规则、右键四项关闭菜单、关闭其它与关闭最后页签、恢复页签；通过界面切换语言和添加提供商后直接查询 SQLite，确认自动保存。浅色/深色主题已查看。自动连接与自动保存的联动问题已修正。
- 尚未使用真实 API Key 调用各家提供商；模型接口通过本机 HTTP fixture 验证。未做正式发布/安装器回归。

## 扩展包示例
语言包目录为 settings.db 相邻的 locales/。例如 en-custom.json：
```json
{"schema_version":2,"id":"en-custom","name":"English (custom)","strings":{"settings.title":"Preferences","settings.general.title":"General"}}
```
主题目录为相邻 themes/，使用 GPUI Component 0.5.1 的 ThemeSet JSON 格式。

## 第二轮优化：编辑页签与固定工具页签

比较三种方案：① 编辑页签可关闭、工具页签固定，职责清晰；② 全部可关闭并增加锁定开关，灵活但状态复杂；③ 右侧仅用图标导航，紧凑但不易识别。采用方案①。

- 编辑区右上角更多菜单、笔记/设置页签右键菜单均增加“关闭全部”，仅影响该编辑组；包含设置时先刷新自动保存，失败沿用重试/放弃/继续编辑。
- 右侧顺序固定为 AI 对话、检查器、表结构。三个页签无关闭图标、无关闭上下文菜单，批量关闭策略也排除它们。返回对话只切换容器激活项，保留原实体和侧栏宽度。
- AI 对话在英文界面显示 AI Chat。同步 GPUI 内置菜单语言，使缩放菜单也随界面语言切换。
- 关于采用 480px 信息卡弹窗：产品标识、版本、发布日期、通道、平台、许可证，以及 GitHub/发布记录入口。
- 发布信息统一在 `crates/desktop/assets/release.json`，`version` 与 Cargo 包版本保持一致；正式发布时设置 `channel: stable` 和 `released_on: YYYY-MM-DD`。当前预览版日期为 null，显示“尚未正式发布”，不把构建日期当发布日期。

### 第二轮验证结果
36 项工作区测试通过，含固定工具页签的批量关闭保护与发布元数据一致性。格式检查、Clippy `-D warnings` 通过。独立原生程序已验证编辑区更多菜单关闭全部、右侧固定页签、返回 AI 对话保持顺序/宽度，以及关于信息卡展示。

同时修复此前工作区漏渲染 `Root::render_dialog_layer` 导致关于/使用帮助弹窗不可见的问题。现有 debug 程序正在运行，保留该进程，通过 `cargo rustc ... -- -o target/layout-second/review.exe` 构建并检查独立验证程序。

## 第三轮：AI 输入区、智能体 Tab 与统一字号

方案比较：① 上方连接/数据库上下文＋底部单行工具栏，层次清晰；② 全部集中一行，窄屏易溢出；③ 全部收入更多菜单，操作成本高。采用①。

- 输入框上方为连接、数据库选择位；当前数据库服务未接入，两个控件禁用并有说明，未写入虚构连接。后续可绑定真实连接/数据库目录。
- AI 对话顶部与输入工具栏的操作使用纯图标及提示。模型是当前选择状态，保留可截断文字和完整名称提示。输入区在未连接时也显示，发送保持禁用。
- 智能体设置直接展示 Codex、Claude、OpenClaw 图标文字 Tab。Codex/Claude 切换当前引擎，保留各自配置、草稿和历史；连接/生成/保存期间或未完成有效自动保存时禁止切换到另一引擎。OpenClaw 仍为扩展配置登记入口，不声明聊天已接入。
- 字号 token 集中在 `typography.rs`：正文/控件 = S；辅助说明 = 0.875S；分组标题 = 1.125S；品牌标题 = 1.25S。S 来自通用设置，范围 12–24px。编辑器字体大小也为 S，编辑区域高度使用 rem；主题重新加载不得覆盖用户字号。
- 没有对话记录时不显示“最新／恢复显示”；有记录且停止跟随时才显示。账号检查成功状态不再占据聊天区，后台日志仍记录；生成进度、结束结果及错误保留，未连接状态用紧凑提示行展示。
- 新增空对话恢复按钮和账号就绪/错误状态的回归测试；工作区测试合计 38 项通过。已验证设置 Tab 切换和 24px 字号自动写入 SQLite，及重启/窄面板下的排版。

## 输出与底部状态栏：采用方案 A

标题为终端图标＋“输出”（英文 Output）。跟随、清空、关闭移至标题右侧纯图标工具条，移除原来的两行宽按钮。跟随开启时高亮，滚动阅读暂停跟随，再点击恢复；清空时显示“暂无执行日志”。日志保留最近 200 条，每条限 2000 字符，使用本地 HH:mm:ss 时间戳及跟随设置的等宽字体；明确错误事件使用错误色和 [ERROR] 前缀，避免只依靠颜色区分。

默认仍收起输出区域。状态栏左侧显示数据库连接状态（当前未接入数据库），右侧显示 AI 未连接/连接中/已连接/生成中；中间只容纳更新检查或设置读取错误等即时反馈，删除固定的内存示例与 SQL Notebook 占位。未增加搜索、筛选、统计或菜单层级。

本轮验证：38 项工作区测试、Clippy 和构建通过。独立空配置实例确认空日志、紧凑工具条；无效 CLI 路径产生带本地时间戳与红色 [ERROR] 的日志，并验证清空和关闭输出入口。

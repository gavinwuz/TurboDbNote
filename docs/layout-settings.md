# 布局与设置中心设计与验收

**目标：** 统一图标文字交互、可关闭页签、分组设置、SQLite 配置与帮助更新入口。

**方案比较：** 工作台页签式保留编辑上下文且适合复杂表单，独立窗口式空间大但切换成本高，抽屉式紧凑但不适合模型高级参数。采用工作台页签式。

**架构：** 保留 GPUI Dock 与已有 Codex/Claude 会话。设置分为通用、智能体和提供商；SQLite 使用事务持久化，首次导入旧 JSON。语言包独立 JSON，内置中文/英文并允许外部覆盖。模型目录和更新检查在后台进行。

**技术：** Rust / GPUI Component 0.5.1 / SQLite / HTTP。

## 实施步骤
1. preferences.rs：新增通用、提供商、扩展智能体数据；SQLite schema 与旧文件迁移；测试重复保存、迁移与错误。
2. 新增语言包模块与资源，应用字体字号和语言选择。
3. settings.rs 与设置表单：分组导航、提供商/协议选择、模型目录、高级 JSON 参数、智能体安装入口。
4. 页签统一标题与关闭菜单；设置关闭仍需处理未保存编辑；Notebook 实体保持存活以支持重新打开。
5. workspace.rs：图标文字按钮、关于、GitHub、后台检查稳定发布版本。
6. 格式、测试、编译、Clippy；双语 README 与变更日志；记录实际验证范围。

## 交互规范
- 4/8/12/16/24px 间距，导航约 160px，表单最大宽度 760px，长内容滚动。
- 使用主题 foreground/muted/border 颜色，选中导航高亮；按钮保留键盘焦点。
- 中文优先系统 UI 字体，英文可用 Segoe UI，编辑可用 Cascadia Code。字号支持 12–24px。
- 网络任务提供加载、空结果、错误和重试；不在切换选项时自动发送 API Key。
- 扩展安装采用显式官方安装入口及本地配置，不静默执行下载脚本。

## 验收
验证左右页签关闭边界、脏设置关闭、重开后编辑保留、SQLite 首次迁移/重复保存、语言包回退、模型目录三种协议及错误、更新 SemVer 比较；原有聊天测试继续通过。

## 用户补充：自动保存
移除所有设置保存按钮；停止修改 600ms 后防抖保存。自动保存不建立智能体连接、不请求推理。页签和窗口关闭前立即刷新；验证失败或写入失败保留草稿，显示重试/放弃/继续编辑。全局外观变更也自动保存。扩展智能体目前提供独立安装入口与配置登记，内置聊天仍为 Codex/Claude。

## 用户确认的图标规则
标题栏操作（包括最大化、最小化、关闭）与最左侧 48px 导航栏（项目、连接、设置、帮助）仅显示图标并保留悬停提示。内容区按钮、设置分类显示图标＋文字。编辑页签显示图标＋标题＋关闭图标；右侧固定工具页签只显示图标＋标题。

## 方案取舍

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 工作台页签＋左分类导航 | 保留编辑实体、适配长表单、易于扩展 | 需管理关闭和辅助区域恢复 | 采用 |
| 独立设置窗口 | 表单空间独立 | 频繁切换上下文、多窗口状态复杂 | 不采用 |

## 实现边界
- SQLite 事务保存完整设置文档，旧 JSON 只读迁移并保留。较新 schema 拒绝降级写入。
- 语言包为独立 JSON；同 ID 外部包合并覆盖，缺失键回退同语言内置包、内置英文。原有示例笔记内容不翻译。
- API 提供商支持配置与按需模型列表获取，三种 API 模式均有本机 HTTP 测试。尚未替换现有 CLI 聊天传输。
- Codex/Claude 保留现有聊天；OpenClaw 和扩展智能体可登记独立程序、目录、安装链接，尚未接入内置聊天。
- 关于展示版本及发布日期状态；0.1.0 是未发布预览版，不填虚构发布日期。
- API Key 在控件中遮罩，但数据库未加密。网络不跟随重定向，错误不输出密钥或响应正文。

## 扩展包示例
语言包目录为 connections.db 相邻的 locales/。例如 en-custom.json：
```json
{"schema_version":2,"id":"en-custom","name":"English (custom)","strings":{"settings.title":"Preferences","settings.general.title":"General"}}
```

## 第二轮优化：编辑页签与固定工具页签

比较三种方案：① 编辑页签可关闭、工具页签固定，职责清晰；② 全部可关闭并增加锁定开关，灵活但状态复杂；③ 右侧仅用图标导航，紧凑但不易识别。采用方案①。

- 编辑区右上角更多菜单、笔记/设置页签右键菜单均增加“关闭全部”，仅影响该编辑组；包含设置时先刷新自动保存，失败沿用重试/放弃/继续编辑。
- 右侧顺序固定为 AI 对话、检查器、表结构。三个页签无关闭图标、无关闭上下文菜单，批量关闭策略也排除它们。返回对话只切换容器激活项，保留原实体和侧栏宽度。
- AI 对话在英文界面显示 AI Chat。同步 GPUI 内置菜单语言，使缩放菜单也随界面语言切换。
- 关于采用 480px 信息卡弹窗：产品标识、版本、发布日期、通道、平台、许可证，以及 GitHub/发布记录入口。
- 发布信息统一在 `crates/desktop/assets/release.json`，`version` 与 Cargo 包版本保持一致；正式发布时设置 `channel: stable` 和 `released_on: YYYY-MM-DD`。当前预览版日期为 null，显示“尚未正式发布”，不把构建日期当发布日期。

### 第二轮验证结果
36 项工作区测试通过，含固定工具页签的批量关闭保护与发布元数据一致性。格式检查、Clippy `-D warnings` 通过。独立原生程序已验证编辑区更多菜单关闭全部、右侧固定页签、返回 AI 对话保持顺序/宽度，以及关于信息卡展示。

同时修复此前工作区漏渲染 `Root::render_dialog_layer` 导致关于/使用帮助弹窗不可见的问题。现有 debug 程序正在运行，保留该进程，通过 `cargo rustc ... -- -o target/layout-second/review.exe` 构建并检查独立验证程序。

## 第三轮：AI 输入区、智能体 Tab 与统一字号

方案比较：① 上方连接/数据库上下文＋底部单行工具栏，层次清晰；② 全部集中一行，窄屏易溢出；③ 全部收入更多菜单，操作成本高。采用①。

- 输入框上方为连接、数据库选择位；当前数据库服务未接入，两个控件禁用并有说明，未写入虚构连接。后续可绑定真实连接/数据库目录。
- AI 对话顶部与输入工具栏的操作使用纯图标及提示。模型是当前选择状态，保留可截断文字和完整名称提示。输入区在未连接时也显示，发送保持禁用。
- 智能体设置直接展示 Codex、Claude、OpenClaw 图标文字 Tab。Codex/Claude 切换当前引擎，保留各自配置、草稿和历史；连接/生成/保存期间或未完成有效自动保存时禁止切换到另一引擎。OpenClaw 仍为扩展配置登记入口，不声明聊天已接入。
- 字号 token 集中在 `typography.rs`：正文/控件 = S；辅助说明 = 0.875S；分组标题 = 1.125S；品牌标题 = 1.25S。S 来自通用设置，范围 12–24px。编辑器字体大小也为 S，编辑区域高度使用 rem；主题重新加载不得覆盖用户字号。
- 没有对话记录时不显示“最新／恢复显示”；有记录且停止跟随时才显示。账号检查成功状态不再占据聊天区，后台日志仍记录；生成进度、结束结果及错误保留，未连接状态用紧凑提示行展示。
- 新增空对话恢复按钮和账号就绪/错误状态的回归测试；工作区测试合计 38 项通过。已验证设置 Tab 切换和 24px 字号自动写入 SQLite，及重启/窄面板下的排版。

## 输出与底部状态栏：采用方案 A

标题为终端图标＋“输出”（英文 Output）。跟随、清空、关闭移至标题右侧纯图标工具条，移除原来的两行宽按钮。跟随开启时高亮，滚动阅读暂停跟随，再点击恢复；清空时显示“暂无执行日志”。日志保留最近 200 条，每条限 2000 字符，使用本地 HH:mm:ss 时间戳及跟随设置的等宽字体；明确错误事件使用错误色和 [ERROR] 前缀，避免只依靠颜色区分。

默认仍收起输出区域。状态栏左侧显示数据库连接状态（当前未接入数据库），右侧显示 AI 未连接/连接中/已连接/生成中；中间只容纳更新检查或设置读取错误等即时反馈，删除固定的内存示例与 SQL Notebook 占位。未增加搜索、筛选、统计或菜单层级。

本轮验证：38 项工作区测试、Clippy 和构建通过。独立空配置实例确认空日志、紧凑工具条；无效 CLI 路径产生带本地时间戳与红色 [ERROR] 的日志，并验证清空和关闭输出入口。

## 统一应用存储

设置、数据库导航、笔记索引使用 connections.db 的 app_documents 命名空间（settings/navigation/note-library），连接与 DPAPI 密文继续使用原表。旧 settings.db 和 JSON 文件作为只读迁移源保留；命名空间存在后不再导入旧源。每项写入事务提交，未来版本拒绝覆盖。SQL 设置内可启用额外元数据查询；其范围不是数据库账号授权。

迁移验证覆盖已存在设置库、仅旧 JSON、空白笔记索引、重复启动不重导入和未来命名空间版本拒绝覆盖；Windows 窗口核对 SQL 扩展自动保存只写统一库。旧设置源保留用于备份，不能将它当作当前运行配置继续修改。

## 中间多分栏

中间页签采用拖动排序、右键向左／右拆分，最多四栏，移动时保留已有编辑实体。固定侧栏和右侧工具不参与拖动。空分栏可接收拖入、新建 Note 或关闭。批量关闭针对所在分栏，暂存修改及运行中的 Note 继续走确认／保存流程。分栏宽度及已重新打开笔记的位置写入 connections.db 的独立 workspace_layout 命名空间；损坏或未来版本拒绝覆盖。布局恢复不恢复查询结果、不自动连接或执行 SQL。

数据库侧栏布局位于设置 → 数据库，以两张平铺卡片展示：两栏布局（上方连接、下方对象）与一栏布局（统一虚拟合并树），默认两栏。卡片展示布局示意图、名称及简短说明，选中项突出显示。数据库标题栏直接显示当前布局图标，悬停说明当前及下一布局，点击立即切换，不再收进更多菜单；重置上下比例仅在两栏布局可用。布局选择随有效设置按 600ms 防抖保存至 connections.db。两种布局保留独立滚动与展开，一栏布局使用 connections.db 中独立版本的目录快照，按连接 ID、目标身份、数据库和分类隔离；运行期请求另核对连接代次。不隐式连接、不改写默认库。展开数据库自动读取本地缓存，缺失时按需完整同步表／视图，其他分类展开时同步；筛选不逐字请求服务器。

Codex 配置将托管安装、路径绑定、认证与推理连接分开。程序目录位于应用数据目录的 agents/codex，版本与校验值固定于服务层；不改写 PATH。独立登录进程不初始化数据库 MCP，不创建线程、不发提示词；取消或超时回收进程。浏览器链接和设备码只在当前界面内存保留，不进入操作日志。Claude 不使用 Codex 安装或认证状态。


合并树的数据库筛选位于对应已连接的连接行搜索图标中，悬停或键盘聚焦显示，激活时保持可见。输入框位于该连接下方，仅按名称忽略大小写筛选已读取的数据库目录；各连接独立保留条件，删除连接时回收。Esc 首次清空、空值时再次收起，输入法组词时交回输入法处理。清空／关闭不修改数据库展开集合、当前选择、连接默认库或会话；关闭非空筛选时图标保持选中。顶部共用一个输入框，右侧漏斗菜单切换连接／库对象过滤范围；切换保留同一个关键词，不再展开第二个全局输入框。库对象范围仅搜索已连接目标。

MySQL 数据库名单取消 512 项总量截断，已配置仅当前库的连接保留其范围。名单与单库对象分批写入 SQLite，本地筛选每页读取 200 项；目录分页不再以 5000 为总偏移上限。筛选跨已连接目标当前已展示数据库的已缓存目录保留连接／数据库／分类层级，未建索引不等同于无对象。连接行刷新名单，数据库行悬停刷新本库已有分类缓存；成功快照原子替换，失败／取消保留上一完整快照。统计与过期说明放入提示，移除重复数量和目录警告行。磁盘、权限、版本、超时及单响应字节保护继续生效；其它驱动的枚举能力与现有边界保持独立。


布局切换图标采用简化框线：两栏为外框加一条横向分隔线，一栏为外框加精简树层级。标题栏与设置卡片共用同一内嵌 SVG，保留当前／下一布局提示、主题色及原有保存值。

Windows 隔离 SQLite 窗口回归覆盖 6200 多个对象的首次自动完整建索引、第 5000 项之后的本地匹配实际显示、筛选不新增远程目录请求、数据库行手动刷新及重启复用原对象快照；连接默认值和 Note SQL 保持不变。MySQL 本地协议模拟覆盖 640 项库名读取及带 BINARY 标记的 UTF-8 元数据，不代表真实 MySQL 或旧版 C 客户端服务端验收。

## 一栏对象筛选的状态与范围

对象筛选仅检索已连接且支持对象浏览目标的本地表、视图和索引快照；未连接目标即使已有缓存也不参与，不自动连接或扫描服务器。连接收起不等于断开，但收起后未展示的数据库不参与新一轮对象筛选。输入防抖期间和后台读取期间保留上一份树，不先展开全部分类；结果与完整层级一次性替换。本地结果按连接分页，更多仍只读取 SQLite。普通目录浏览分页与筛选结果隔离，只有完整目录快照、连接范围或数据库展开范围改变才重新检索。

状态区分等待、查询中、有结果、无匹配、未缓存和失败。失败保留旧结果并提供明确重试；未缓存显示选择数据库入口，点击清空筛选并展开连接，再由用户选择数据库及对象分类建立缓存，不把未加载分类显示为失败重试。断开、重连、快速输入及目录更新以请求序号、连接代次和目录修订丢弃过期结果。筛选内的连接／数据库／分类折叠是临时状态，清空后恢复普通树。

SQLite 命名空间初始化只执行一次事务；后续本地筛选不争用写锁。实际对象操作继续核对当前连接及服务端，不将缓存视为实时结构或执行授权。

Windows 隔离 SQLite 窗口回归覆盖空缓存直接输入、6200 多个对象中匹配显示、已有缓存的第二目标断开后排除、等待／读取阻塞期间保留旧树、过期任务取消记录、快速输入、失败保留及显式重试、全部断开时不读取缓存，以及“更多”仅追加一次本地读取且不重启搜索。连接配置与 Note SQL 保持不变；此验证不是实际 MySQL 服务端或 Linux 桌面验收。

## 单入口过滤与数据库可见规则

一栏树在目录溢出时常显独立滚动条；数据库名单的“加载更多”位于当前已加载数据库及其展开子节点之后，仍逐批读取本地 SQLite，不自动读取全部对象。顶部漏斗菜单选择过滤连接或库对象，共用一个可清空的关键词输入框。

连接右键菜单提供“配置数据库过滤器”与规则启用开关；展开连接的数据库快速过滤行也提供设置图标。规则按连接保存到导航命名空间，支持每行一个包含／排除模式，`%` 和 `*` 匹配任意长度字符，其余字符按字面处理，忽略大小写，排除优先；包含留空表示全部。最多各 32 条，每条 256 字符；存储超限时保留弹窗并提示。数据库规则先在 SQLite 中应用再分页，并限制对象搜索的数据库范围。配置及切换规则不连接服务器、不修改默认数据库，不替代执行权限；Note 顶部及 SQL 单元数据库候选列表也应用连接的包含／排除规则；已有目标及手动输入不被改写，规则不是执行权限。

Windows 隔离窗口验证覆盖一栏溢出滚动条、连接／库对象范围切换保留关键词、筛选不增加本机占位网络连接、SQLite 连接规则保存与重新打开。SQLite 目录回归覆盖超过首批分页的包含匹配、排除优先及对象搜索同范围过滤；这些验证不代表真实 MySQL 服务端验收。

## 三类筛选与账户层级

漏斗按钮不附加下拉箭头；菜单单选连接／项目／驱动、表／视图／索引、存储过程／触发器／函数／事件三类，切换保留关键词。连接搜索按空白分词并取交集，也保留原有地址等连接信息检索。两类库对象搜索仅查 SQLite 已发布快照，输入时冻结普通树已经展示的库名，只有其中已展开的数据库参与对象检索，未展开连接、数据库分支收起、数据库规则排除、临时过滤隐藏以及尚未分页加载的库不参与。更改关键词或切换对象类别保留库名集合；在筛选中展开／折叠数据库会更新检索范围，折叠库名保留。清空后从普通树重新取库名集合；请求仍绑定连接代次、类别与目录修订，不自动建立连接或读取远程元数据。

连接下增加数据库与用户／角色同级分支。数据库分支默认展开，库名、分类、对象及列依次缩进；加载更多位于库列表尾部，左侧与库名对齐，右侧圆圈加号，加载时换加载标记。MySQL／MariaDB／TiDB、PostgreSQL 与 ClickHouse 账户分支仅在展开时读取用户或角色名称，每页 200 项，最多展示 20000 项；支持手动刷新及失败重试，不查询密码或认证材料，账户名单不查询认证材料；创建能力及只读权限查看见下文。不支持的驱动隐藏账户分支；权限不足提示检查当前账号权限，不提权、不循环重试，重连后丢弃旧代次账户结果。

Windows 原生隔离窗口及本机 MySQL 协议模拟验证覆盖三类漏斗菜单、数据库／用户分支、账户读取与手动刷新、尾部名单分页保持本地读取、Note 顶部及单元候选同步规则，以及预置本地快照中隐藏库的同名对象不进入表和程序对象结果。规则保存及原有 SQL／数据库目标保持已核对；本次不是实际 MySQL／PostgreSQL／ClickHouse 服务端或 Linux GUI 验收。

## 用户右键操作与直接权限查看

用户／角色分支及具体用户行使用独立裁剪命中右键菜单。分支提供创建新用户，用户行另提供查看权限。账户管理首期适配 MySQL 系列：创建要求可写的 MySQL 5.0.2+ 兼容连接，直接权限查看要求 MySQL 5.0+；未适配的驱动保留禁用入口及能力说明，不假装可用。

创建表单为用户名、来源主机（默认 localhost）和遮罩密码，输入均可清空。预览前冻结字段与目标并读取当前会话 SQL 模式，预览／复制的密码固定显示 ***。复用 SQL 预览及执行二次确认，禁止修改脱敏预览后执行；执行再次核对连接代次、可写能力与 SQL 模式。只执行单条 CREATE USER，不使用 IF NOT EXISTS，不覆盖旧用户、不自动授权或重试；失败／结果不明先刷新名单核对。密码只在运行期内存及受控会话通道传递，Draft 调试输出脱敏，成功后清除表单密码。

权限弹窗复用只读网格，按范围、数据库、对象、列、权限、可转授展示，每页 200 行，过滤回车／应用才读取，分页保留已应用条件；支持刷新和失败重试。仅读取当前会话可见的直接全局／库／表／列权限，不读取认证字段，不使用可能包含认证材料的原始 SHOW GRANTS，不推断角色继承、动态权限或最终有效访问。空列表不等同于无权限，断开或重连清除旧结果，失败保留结果并标明可能过期。

MySQL 账号采用独立用户名与主机字段，不从展示的 user@host 反向拆分；转义复核会话 SQL 模式。参考 [MySQL 账号名称](https://dev.mysql.com/doc/refman/8.0/en/account-names.html) 与 [权限目录说明](https://dev.mysql.com/doc/refman/8.0/en/information-schema-user-privileges-table.html)。

## 分组平铺的直接授权编辑

权限弹窗按全局／库／表／列作用范围分组，权限以标签平铺；转授状态在组内显示。原始直接授权完整读取但限制最多 2000 项，超限报错而不把截断内容当作快照。过滤作用于展示，不缩小保存前的对比范围。编辑态可增加范围、勾选权限、撤销本范围或切换转授；更改仅暂存并标记待新增／待撤销，取消恢复，原账号不删除。

预览冻结账号、目标连接／环境、原授权与期望授权，由服务层白名单编译 GRANT／REVOKE；不能修改预览 SQL 后执行。执行二次确认后复核连接代次、账户仍存在与原直接授权快照，冲突要求刷新。服务端各授权语句可能独立提交，失败停止，不自动重试或声称整批回滚；刷新核对部分生效情况。全局和 GRANT OPTION 影响范围在确认中明确提示。MySQL 转授是作用范围能力，列级转授编辑保守限制为表级审核；新增库级模式名称中的 %、_、反斜杠要求原厂工具审核，精确对象可使用表级授权。只适配已列白名单的静态直接权限，不处理角色、动态权限及例程授权，不读取认证字段。

Windows 隔离窗口与本机 MySQL 协议模拟回归覆盖分组标签、暂存待撤销标记、取消编辑无写入、SQL 预览无写入、关闭二次确认无写入，以及明确确认后只发出一次撤销、比较原授权并刷新为新快照。协议模拟不代表真实 MySQL 权限系统或 Linux GUI 验收；实际账号管理还依赖服务器权限、版本及授权范围。

## 用户权限中间页签

用户右键查看权限打开“目录／对象／权限”工作台，同连接同账号复用页签，接入中间页签顺序、分栏和恢复。恢复只显示上下文并等待显式刷新，不自动连接、读取授权或执行变更；草稿不写入布局存储。数据库与对象使用独立滚动和本地筛选，目录渐进显示，对象按已发布 SQLite 快照分批读取，未缓存目标可通过增加范围手填，不隐式扫描服务器。

窄面板收起对象栏为选择菜单，宽面板允许拖动分隔线。权限行显示直接授予与可转授；MySQL GRANT OPTION 实际由同一对象范围共享，修改时同步该范围，列权限不开放新增可转授。新增、撤销与可转授修改分别计数；全选不删除未知权限、不降低已有转授状态。切换范围保留全部草稿，刷新和关闭明确处理未保存变更；预览与二次确认仍绑定原授权、目标连接及连接代次。

Windows 原生窗口使用隔离的本机 MySQL 协议模拟器验证权限工作台：范围切换保留草稿，取消关闭或执行确认不写入，SQL 预览后明确确认仅执行一次撤权，执行前复核原授权并刷新结果。窄布局、底栏计数与按钮位置、恢复页签不自动读取授权均已验证。此为协议模拟与窗口验证，不代表真实 MySQL 服务端授权或 Linux GUI 验收。

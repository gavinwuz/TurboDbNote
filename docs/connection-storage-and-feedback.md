# 连接存储、凭据与交互反馈

## 方案比较

| 方案 | 做法 | 取舍 |
| --- | --- | --- |
| A（采用） | 独立 SQLite 连接库＋系统凭据/会话内存＋共用反馈组件 | 配置和时间记录事务一致，密码独立管理，复用现有依赖 |
| B | JSON 增加时间字段 | 改动较少，但并发写入与记录查询不便 |
| C | 自建加密密码库与主密码解锁 | 可跨设备，但增加配置、解锁与密钥恢复成本 |

## 存储位置与迁移

- 安装版：`%APPDATA%\TurboDbNote\connections.db`。
- 绿色版：程序旁的 `data/connections.db`。
- `settings.db` 继续保存通用/AI 设置，`database-navigation.json` 保存布局、分类顺序等导航偏好。
- 连接的“更多 → 存储与使用记录”显示创建、修改和最近使用时间，提供“打开所在文件夹”，不显示具体路径。
- 首次事务导入相邻 `connections.json`；原文件保留作备份，不再双写。删除连接后不会从旧 JSON 重新导入。旧导航文件中已知的创建日期按原精度保留，其余历史时间为 NULL，不以迁移时间冒充。
- 存储带应用标识和 schema 版本；支持早期 SQLite v1 升级到带加密密码表的 v3，拒绝未知未来版本。迁移失败会回滚，阻止覆盖原配置。
- `connections` 表保存连接 UUID、无密码的配置 JSON、`created_at`、`updated_at`、`last_used_at` 和系统凭据引用。创建时间不随编辑改变；使用时间不被配置保存覆盖，较晚到达的旧时间不会倒退新时间。
- 新时间以 UTC RFC3339 保存，界面按本地时间显示/分组。成功连接及成功的数据库操作更新使用时间；失败连接不进入最近使用。测试连接不等同于业务使用。
- 提供“按创建日期”“按使用日期”分组；两种日期模式均不显示“最近”，分组/环境模式仍保留最近 5 条。
- 数据库初始化、迁移与写入在后台执行；WAL 和忙等待处理短时并发。每次只更新目标记录及相关元数据，不重写整个连接列表。

## 密码语义（SQLite v3）

- 采用 Windows 当前用户 DPAPI；不设置应用密钥或环境变量。加密密码存入 `encrypted_passwords` 的 BLOB，连接参数 JSON 不包含密码。
- 新建网络连接默认开启“保存密码”，已有连接保留原选择。关闭时显示图标提示密码仅留内存、退出或重启需重新输入；若原来已保存，提示保存连接后移除持久密码。保存时密码密文、随机引用和配置在同一 SQLite 事务提交，失败全部回滚。
- DPAPI 附加熵绑定凭据引用，禁止替换其他引用的密文；系统保护通常绑定当前 Windows 用户和电脑。跨机器复制后需重新输入密码。
- 升级旧 SQLite v1/v2 或 JSON 后，后台读取旧系统凭据、加密并事务提交，再清理旧凭据；失败保留旧数据并提示，可下次重试。缺失旧凭据或解密失败不能静默覆盖为空。
- 编辑时异步加载密码，默认遮罩，眼睛按钮切换显隐。回填值未修改或留空表示沿用；清除需确认且保存后生效。
- 修改主机、端口、用户或驱动类型不得自动复用旧目标密码。复制配置不复制密码。
- 文件中只有密码字段加密，主机、库名及时间等配置仍为普通 SQLite 数据。

## 统一交互规则

- 对话框底部按钮使用共用操作栏，右对齐、间隔 12px，关闭/取消在前，确定/执行在最右；按钮使用图标＋文字。
- SQL 对话框统一“关闭 / 复制 / 执行”。执行会冻结 SQL 和目标并再确认；取消不发送请求，确认后仍校验连接代次及表结构。
- 普通操作完成使用带图标的浮动消息；同文案合并，错误消息保留至关闭。数据库连接、测试、保存、断开、复制及导出不再依赖底部静态状态框。
- 删除连接、数据库写入、清除密码、降低 TLS 保护、启用旧密码认证，以及删除提供方/智能体配置、清空输出日志、舍弃未保存设置使用确认框。
- 原生文件选择器继续负责文件操作；不绕过覆盖确认，SQLite 新建文件仍拒绝覆盖已有文件。
- 索引使用本地 IDX 矢量标识，主键列使用钥匙，导入/导出使用开口方框及右上角进入/离开箭头。资源随程序嵌入，支持主题着色，不增加运行时下载。

## 验证

- 单测覆盖迁移失败回滚、旧 JSON 保留、未知时间、时间不倒退、旧 SQLite 升级、凭据引用原子替换、已退役凭据清理、密码留空/清除/目标变更语义。
- 隔离 Windows/MySQL 8.0 实测：保存后密码框为空仍能连接；编辑名称后可继续连接；新进程无密码输入时读取系统凭据认证；清除需确认并保存，随后系统凭据消失。测试凭据使用随机 ID，验证后清理。
- 原生 SQLite 窗口验证：SQL 预览不写入，关闭二次确认不写入，明确确认才执行；按钮位置与图标、连接结果浮动消息均检查。

旧版本验证结果：全工作区 81 项测试通过，Clippy（`-D warnings`）和格式检查通过；原生回归覆盖 SQLite v2 迁移、确认框取消/回车执行、使用日期分组与重启恢复。

## 连接测试与 TLS 简化

- 测试连接和检测数据库不要求名称、数据库名；保存时才校验必填。SQLite 测试仍需要文件路径。
- TLS 失败弹窗提供关闭和“禁用 TLS 并重试”，明确说明连接不再加密；只重试一次，失败保持原配置。服务器明确要求 TLS 时不提供降级重试。
- 成功后仅对与已存配置一致的连接保存 TLS 选项，保留原密码引用与其他字段；新建或已修改的草稿仅更新 TLS 选择，完成信息后手动保存。

此前增量验证：81 项工作区测试通过；原生隔离窗口验证系统密码重启遮罩回填、查看切换、名称留空测试与保存提示、数据库筛选和空态；HTTP 协议模拟验证 TLS 成功后保存及失败不保存（不等同于真实 ClickHouse 服务端验收）。

当前 v3 存储验证：84 项工作区测试通过，新增 DPAPI 密文随机性、引用绑定、篡改拒绝、原子保存回滚和旧凭据迁移回滚测试。

原生隔离窗口与 HTTP 模拟验证：旧凭据迁移后系统凭据被清理，双击及重启后认证使用正确解密值；查看记录无具体路径、打开所在文件夹可定位；复制不带密码，删除取消保留、确认删除同时清除密文且保留其他草稿。

连接和表菜单使用独立状态 ID，并经 GPUI 裁剪后的命中检测授权；分类、列、索引及空白区域不会触发隐藏连接行的菜单。

菜单范围增量验证：隔离窗口加入 35 条额外连接产生滚动裁剪；连接菜单与表菜单各自正确，表分类、列、索引和空白区域不显示连接菜单。新建 MySQL 默认保存，已有关闭配置保持关闭并显示内存提示；相关表单单测、Clippy 和编译通过。

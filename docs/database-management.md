# 数据库管理入口、建库与迁移

采用方案 A：数据库标题栏集中“新建项目 / 打开最近连接 / 导入连接 / 分类方式”四个图标。备选 B 为侧栏折叠最近分组，仍占用列表；备选 C 为独立连接中心，需要额外切页。

最近连接最多保留 5 条，只在打开菜单显示；每项单行展示连接名、灰色主机:端口/库名（SQLite 为文件名）与最近使用相对时间，时间在打开菜单时重新计算；点击已连接项切换库对象，未连接项执行连接。连接列表不重复展示“最近”分组。库对象已连接时仅显示库名，未连接、连接中和加载中保留状态，分类节点自身数量保留。

## 建库与复制

- MySQL 新建库可选择或输入字符集，支持 utf8mb4、utf8、GBK、GB2312、latin1 等，实际支持由服务端决定；早期版本不展示 utf8mb4 预设。MySQL 4.0 只用服务器默认字符集。
- PostgreSQL 可指定编码，使用 template0 创建，仍受服务器区域设置与权限限制。ClickHouse 没有库级字符集选项，SQLite 新文件使用既有默认编码。
- “库对象”的新增菜单提供“复制数据库”。默认只复制结构，可勾选数据；操作前确认连接、环境、目标及内容，目标必须不存在。
- MySQL 快速复制支持普通 InnoDB/MyISAM/MEMORY/HEAP/Aria 表，包含列、索引和外键，最多 200 张表。不复制视图、触发器、存储程序、权限或外部存储表；数据按表复制，不提供全库一致性快照。先读取定义，再创建所有目标表、复制数据、添加外键，不关闭外键检查；源库引用改为目标库引用，外部库引用保持原样。默认继承源库字符集/排序规则，显式字符集仅改变新库默认值，不转换已复制表的编码。
- MySQL 失败时保留新目标供检查，不自动删除或重试；超时须重新确认目标状态。已有目标不会被覆盖。
- SQLite 结构复制包含表、索引、视图和触发器，并保留编码；结构复制不支持虚拟表。完整复制使用分页备份快照。先写同目录临时文件，成功后原子发布，不覆盖已有文件。
- PostgreSQL 复制通过原生工具执行；ClickHouse、Redis 暂不提供直接复制入口。复制完成后可新建连接指向目标，不自动改变已有单库连接配置。

## 第三方连接导入

支持 Navicat NCX、DBeaver data-sources.json，以及包含该文件的 DBeaver 项目 ZIP。只读取用户选择的文件，不扫描其他工具目录。NCX 未声明驱动类型时，使用用户先选择的类型。

导入预览允许补齐数据库名和用户名，缺失必填项不能保存。名称冲突自动追加编号并在预览显示。批量追加使用 SQLite 事务，不覆盖现有连接，不自动连接；单次和本地连接总量上限均为 200。

密码、密钥、启动脚本和高级网络配置不迁移；启用的 SSH/代理/TLS 自定义配置、无法保留的只读限制、未知数据库类型等跳过并计数。导入后需手动补充认证信息、核对 TLS。ZIP 只读取连接定义，绝不读取 credentials-config.json 或解压文件到磁盘。

格式参考：[Navicat 官方连接导出说明](https://help.navicat.com/hc/en-us/articles/218281627-How-to-get-the-connection-information-when-migrating-Navicat-to-new-computer)、[DBeaver data-sources.json 结构](https://dbeaver.com/docs/dbeaver/Data-Sources-Json-Reference/)。NCX 字段参考 DBeaver 官方迁移实现。

## 验证

工作区 102 项测试、Clippy（零警告）与调试构建通过。单元测试覆盖字符集转义、结构/数据复制、目标不覆盖、连接批量原子追加、NCX/JSON/ZIP 解析、敏感信息排除和不支持配置跳过。隔离 MySQL 5.1 与 4.0 实例验证建库字符集、普通表/外键/数据复制与不覆盖。原生 SQLite 窗口验证最近入口、统计移除、复制取消不写入、确认后仅结构，以及 NCX/DBeaver 预览、补全和保存。PostgreSQL 编码生成已测试，尚未进行实库建库验收。

## 连接编辑

已连接时允许修改表单草稿，当前会话继续使用原配置。保存先校验必填项与凭据，再确认断开当前会话（取消正在执行的操作）；确认后保存，新配置在下次连接生效。取消确认保留会话及草稿。环境下拉色块与连接前缀复用同一颜色映射，自定义未知环境使用灰色。

新版统一导出、复制及导入任务窗口、进度与限制见[数据库传输工作台](database-transfer.md)。

数据库连接的自定义分类现统一称为“项目”：侧栏按项目组织，连接表单使用项目字段，可选择已有项目或新建项目；空值显示“未指定项目”。已有配置的 `group` 字段、分类内容、排序与折叠存储键保持兼容。

新建项目入口位于数据库标题栏最前方，使用项目文件夹加号图标；分类方式菜单不再包含新建项目。在其他分类视图中点击该按钮仍创建项目，保存后切换到按项目显示，取消保持原视图。

分类行移除右侧新增按钮，保留折叠与拖动排序；新建项目统一使用标题栏入口。

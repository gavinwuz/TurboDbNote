# Database icons

The five `db-*.svg` brand marks are distributed by [Simple Icons](https://github.com/simple-icons/simple-icons), retrieved 2026-09-20. Source slugs: mysql, postgresql, sqlite, clickhouse, redis. CC0 license: `simple-icons-LICENSE.md`. Trademarks remain with their respective owners. These identify connection providers; they do not imply endorsement. SVG paths are unmodified.

`project-add.svg`, `name-generate.svg`, `group-list.svg`, `current-time.svg`, `page-first.svg`, `page-last.svg`, `row-count.svg`, `index.svg`, `key.svg`, `import.svg`, `export.svg`, `refresh.svg` and `focus-cross.svg` are original project vector assets under the repository license. They contain paths only, with no font dependency.

- `note-run.svg`, `note-insert-before.svg`, `note-insert-after.svg`, `note-delete.svg`: original 24px toolbar line icons for Note cells.

- `note-save.svg`, `note-run-all.svg`, `note-collapse.svg`, `note-expand.svg`: original document toolbar line icons.

- `note-sql.svg`, `note-md.svg`: original outlined SQL / MD letterforms for notebook cell insertion, maintained with this project.

`note-frame.svg` and `note-file.svg`, revised `note-sql.svg` / `note-md.svg`: original neutral document outline and type badge masks, composed with theme-aware colors.

`task-boxes.svg` / `task-lines.svg`: original three-row unchecked task list masks; accent boxes and neutral lines.

# 数据库传输工作台

采用统一任务窗口：来源与目标、内容选择、预览、确认执行、进度。相比三个独立弹窗可减少重复操作；相比多步向导更便于核对全部目标。

- 连接配置的数据库作为默认浏览库，连接后可以搜索和切换其他库，不修改保存配置。
- 库对象标题栏可直接导出数据库，无需先选表。结构与数据可选。
- “复制数据库”固定来源为当前连接及浏览库，目标连接默认同源，也可选择其他同类型连接。只创建新目标，默认仅结构；新库继承源库字符集与排序规则。
- 导入支持其他连接或用户选择的 SQL 文件。文件预览时创建临时快照，确认执行使用同一份文件，防止预览后文件被替换。
- 后台处理使用有界缓冲和临时文件，进度展示实际字节、页或对象数量；未知总量不伪造百分比。原生客户端发送完数据不代表已提交，须等待进程成功退出。
- 可取消；网络库失败或取消可能留下已创建的库、对象或部分数据，不自动删除、不自动重试。导出与 SQLite 新文件不覆盖已有文件。

## 驱动范围

MySQL 现代版本通过 mysql/mysqldump 流式迁移，工具从既有 PATH 发现；连接间复制普通表、索引与外键，不包含视图、触发器、存储程序、事件与权限。文件导出可包含相应结构对象。旧版同连接复制复用适配器，最多 200 张普通表，非全库一致性快照；旧版文件导出需要兼容客户端工具；文件/跨连接导入尚未接通安全执行通道。

PostgreSQL 使用 pg_dump、psql、createdb，目标继承来源编码与区域设置。需兼容原生工具；目前未完成真实 PostgreSQL 服务端验收。

SQLite 完整 .db 导出和复制使用分页备份，包含虚拟表和大字段；SQL 导出按行流式生成，支持普通表、索引、视图、触发器，不支持虚拟表。SQL 单条语句上限 8 MiB，超限使用完整 .db 备份。历史自增序列状态应使用完整备份保留。

仅支持同类型且版本兼容的迁移，不自动转换不同方言。含结构的连接导入需要空目标。临时文件需要足够磁盘空间。

## 凭据与 SQL 文件

原生工具凭据通过仅当前用户可访问的临时文件传入，正常结束、失败与取消后清理；密码不放命令行参数或环境变量。SQLite 禁止 ATTACH/DETACH、扩展加载及危险配置修改。PostgreSQL 文件预检拒绝本地命令，允许受限 dump 标记与 COPY 数据；普通字符串内的反斜杠被保守拒绝，请采用标准 E 字符串。COPY 数据流不受普通 SQL 行 8 MiB 上限约束。

## 验证

SQLite 回归覆盖大字段、结构与数据、生成列、取消、禁止覆盖、文件快照和外部文件写入防护。隔离 MySQL 8.0 双实例验证文件导出导入与跨连接复制。原生窗口已验证 SQLite 导出全部 205 行、跨连接导入、SQL 快照，以及 MySQL 默认库优先和手动切库。测试不接触用户数据库。

## 传输布局与参数

采用来源在左、目标在右、中间单向传输箭头的单页布局。左右共用标题行与首行控件基线，库名等附加说明放在控件下方，不将另一侧整体垂直居中。相比四步向导减少反复切页；相比全屏工作台更适合日常导入导出。下方依次为对象/数据参数、可搜索表清单、网格预览。

导出建议文件名为 `数据库名_YYYYMMDD_HHMMSS_毫秒.sql`，完整 SQLite 备份使用 `.db`。不能覆盖已存在文件。选择部分表时使用 SQL 格式；表相关索引随结构导出，独立视图不隐式加入部分表任务。MySQL 文件导出可选视图、触发器、函数/存储过程、事件；SQLite 可选视图和触发器；驱动不具备或尚未接通的选项禁用。PostgreSQL 结构对象沿用原生 dump 的关联规则，不能单独切换函数/触发器。

连接预览展示真实列名和最多 5 行、16 列数据，单元格预览有界；点击表旁预览图标切换示例表。SQL 文件预览展示脚本行号及正文，不执行脚本来生成数据，不按表筛选或改写脚本。

连接间仅数据导入提供追加、覆盖和主键更新。默认追加；包含结构时写入模式不可切换。MySQL 覆盖采用 TRUNCATE，SQLite 使用事务内 DELETE；MySQL 外键引用阻止 TRUNCATE，其他唯一索引阻止“仅按主键”更新，避免误更新。SQLite 保持整个任务事务，失败或取消回滚；MySQL 原生客户端可留下已提交批次，风险在确认框说明。PostgreSQL 与旧版 MySQL 高级模式尚未接通，明确禁用。

分批默认 1000 行，范围 1–10000；这是每批上限，按宽表参数数和约 4 MiB 的语句大小进一步缩小。SQLite 文件备份按页处理，不使用行批次。MySQL 仅数据模式按列类型生成 SQL，保留二进制和 UTF-8 文本；单行编码超过 8 MiB 或空间类型须改用原生 SQL 文件传输。原生 mysqldump 输出重组只作用于工具生成的 INSERT，绝不改写用户 SQL 文件；超大原生行继续单行流式输出。

新增回归已验证 SQLite 部分表导出、三种写入模式、外键失败回滚；隔离 MySQL 双实例覆盖大字段、JSON、中文、时间默认值、二进制和未选中表保护。原生窗口验证系统保存窗口的默认文件名、左右布局、表选择、网格预览及 SQLite 按主键更新 205 行。SQL 文件预览限首 32 KiB、最多 200 行，执行仍使用完整冻结文件。

## 新库、已有库与执行预检

复制入口统一称为“复制至新库”，只创建新目标，存在即停止。窗口左侧显示来源库名和检测出的字符集，目标默认同一连接。导出提供文件、新库、已有库三种目标；已有库默认推荐按主键更新插入（已接通的 SQLite/现代 MySQL），也可选择追加或清空后插入。缺少主键或目标表不匹配时提示处理，不静默退回其他写入模式。

执行预检使用与传输相同的客户端，检查源、目标连接、相关工具、目标存在性、表结构与主键。MySQL 新库操作不将尚未创建的目标当作登录默认库。旧版预览/同连接复制使用兼容适配器；文件导出按驱动位置与既有 PATH 选择匹配的 5.1/5.6 客户端，不误用现代客户端。5.1 只能用于已明确允许旧认证的配置，不自动降低 TLS 或认证策略。旧版文件/跨连接导入安全执行通道尚未接通，会在预检明确拒绝；PostgreSQL 高级覆盖/更新模式仍未开放。预检不能保证网络或权限在执行期间不变。

## 输出与草稿

连接、数据库操作、预检及传输阶段接入底部输出。内存最多 200 行，每行最多 2000 字符；传输进度每秒至多追加一次。后台磁盘日志位于应用数据目录的 logs 中，可通过输出栏文件夹按钮定位，不在面板显示完整路径。每卷约 10 MiB，保留完整分卷；256 条有界写入队列过载时记录丢弃计数，磁盘失败在界面提示。日志只含任务 ID、操作类型、阶段、时间、耗时、数值计数及错误类别，不包含连接串、SQL、密码、密钥或原始服务端错误。

关闭未保存连接编辑页，或切换编辑其他连接时，提供“继续编辑／放弃修改”。放弃只丢弃草稿，不删除已保存连接；随后明确加载所选连接，不把旧草稿伪装成该连接的配置。

## 退出码 2 的修复

退出码不是具体失败原因。已在隔离 MySQL 4.1 + 5.1 客户端中复现：mysql 支持的 secure-auth 参数不能直接传给该版 mysqldump。现按具体工具能力生成参数，5.1 mysqldump 不接收该选项，且只有明确允许旧认证的配置才允许选用它；其他旧客户端在使用相关认证选项前检查实际支持能力。不通过忽略退出码或自动降低认证保护掩盖失败。

原生客户端 stderr 仅在内存中读取有界前缀并立即归类，其余内容丢弃，不进入日志。错误区分不支持参数、认证、权限、网络、TLS、目标冲突、SQL/版本不兼容及磁盘写入；仅展示固定提示、已知错误码及白名单选项名称。导出失败不再提示可能写坏来源；写入失败仍提醒核对已提交内容，均不自动重试。

本次原生窗口回归完成：MySQL 4.1 同连接复制结构和中文数据、重复目标预检阻止、5.1 客户端文件导出及兼容客户端回读、SQLite 导出至已有库并按主键更新、草稿取消/放弃后加载已保存配置，以及底部输出与磁盘事件记录。PostgreSQL 仍未进行真实服务端验证。


## 目录加载与导出诊断

打开非文件导入任务后自动在后台加载库对象目录，不读取样本行；切换来源连接/库时延迟 400ms 重新加载，取消旧请求并检查连接快照。目录受现有元数据上限约束，保留服务端返回的能力/截断说明。表默认全选并可逐表勾选；其它对象按驱动已实现的类别选择，目录列出对应名称，不能把 PostgreSQL 或旧 MySQL 未支持的细粒度选择描述为已实现。样本数据仍由“读取预览”明确触发。

MySQL 导出先读取选定 mysqldump 的 --no-defaults --help，按实际选项支持附加 --no-tablespaces、--set-gtid-purged=OFF、--column-statistics=0，并关闭表锁选项；不再仅凭 8.0/8.4 版本子串判断。不会自动改权限、关闭 TLS 或重试。真实对象 SELECT/SHOW VIEW/TRIGGER/EVENT/例程权限不足仍需要调整选择或由管理员授权。

错误分类识别 mysqldump 行尾括号内的已知错误码，分别提示 PROCESS、RELOAD/FLUSH_TABLES、例程与对象权限；导出错误说明源库读取权限，不再误指为目标库。仅保留固定类别和数字码，不输出原始 stderr、对象正文或凭据。退出码 2 本身不能确定错误根因。

本轮 Windows 隔离窗口验证：打开导出即加载两张表、视图和触发器；取消部分表后读取预览、确认导出 SQL，再导入内存 SQLite 核对只包含所选表。MySQL 客户端能力与错误分类为回归模拟验证；尚未取得用户服务器版本/具体错误码，不能宣称其权限问题已真实服务端验收。


## 可选预览、对象树与文件结果

SQL 文件导出无需先读取样本预览；自动目录加载完成后可以直接确认执行，仍保留连接与目标预检。表列表带滚动条，视图／触发器／例程／事件按类型折叠。SQLite 视图与触发器、现代 MySQL 视图可逐项排除；其它对象依驱动能力按类型控制，部分表模式的关联对象范围保持原有规则。

MySQL 目录对可见的每类对象抽样检查一个定义的读取权限；失败显示固定类别提示，用户可取消该类型继续导出，不自动忽略已勾选对象。元数据可见性和运行期权限可能变化，抽样成功不保证所有对象可导出，隐藏对象也无法据此完整识别。

SQL 文件头包含 `-- Exported by TurboDBNote`；默认 LF，可选 CRLF。使用有界流式转换、同目录临时文件及不覆盖发布，字符串／引用标识符／PostgreSQL dollar 正文中的原始换行保持不变以免改写数据。成功页提供打开导出目录；SQLite 二进制备份不写入文本头。

本轮 Windows 原生窗口验证：未点击读取预览直接导出 31 张 SQLite 表，排除一个视图、保留触发器，回读 SQL 后核对结构与数据；校验 TurboDBNote 文件头及 CRLF，成功入口实际打开了导出目录。MySQL 新权限抽样提示尚未做真实服务端验收。


## MySQL 自动兼容识别

默认连接先读取最多 4096 字节的服务器 greeting（版本字段最多 128 字节），不发送账号／密码；MySQL 4.0、4.1、5.0、5.1、5.5 选择已有隔离兼容辅助进程，5.6 及以后走现代适配器。MariaDB 版本前缀不按 MySQL 5.5 兼容处理。探测与连接共享超时，取消释放底层会话，认证失败不切换客户端重复尝试。

发行脚本继续集成固定校验的兼容客户端与许可材料；版本／客户端覆盖收进连接高级项。缺少组件时提示到驱动设置修复。兼容客户端 TLS 能力和旧认证限制保留：需要时仍明确提示用户选择安全策略，不因旧版本或本机地址自动放宽。已连接的实际版本用于后续 Note／传输快照的适配器选择，不改写用户保存的配置。


## 随包兼容客户端

`build-preview.ps1` 与 `package-windows.ps1` 共用 `stage-mysql-driver.ps1`，从固定 tools 缓存准备 DLL、COPYING、README.mysql、provenance.json 和配套源码压缩包，逐文件校验复制结果。ZIP 与 Inno Setup 使用同一个 staging 目录，安装规则递归携带 drivers。缓存不通过正常 target 清理删除；首次准备需要联网或显式提供官方 ZIP／源码归档，完整缓存后无需重复下载。

主程序与 `turbodbnote-mysql-legacy.exe` 同级，DLL 位于 `drivers/mysql-5.1.73-winx64/libmysql.dll`。客户端约 2.54 MiB，含配套源码和许可整个组件约 25.47 MiB，不包含完整 119 MiB 下载 ZIP 或 mysqld 服务端。已检查固定 DLL 为 x64，仅依赖 KERNEL32、ADVAPI32、WSOCK32、WS2_32 系统库，无额外私有 CRT DLL。

本轮验证：固定官方归档与 DLL 校验通过；共享暂存步骤两次命中缓存，预览／发行暂存目录逐文件一致，测试 ZIP 全部条目哈希一致且不含服务端或完整下载 ZIP，Inno 递归安装规则包含 drivers。Windows 原生窗口显示旧版组件可用；辅助进程加载 DLL 并完成隔离 MySQL 8.0.30 握手后，按版本保护正确拒绝非目标 8.x。此项不等同于 4.x／5.5 真服务器验收。本轮未生成完整 Release 安装器或发布。

执行不再依赖样本预览；SQL 文件仍按用户选定原始脚本执行。连接传输保持目标预检、明确确认及结构校验。现代 MySQL 的 CLI 传输可选择视图、触发器、例程、事件类型，个别对象的排除仍受客户端能力限制；旧版同源快速复制范围不变。新库排序规则默认继承源库，手动覆盖仅适用于现代 MySQL 且须在建库前验证目标服务器支持与源字符集匹配。

来源库支持搜索选择和手动刷新目录。现代 MySQL 自动目录读取后，使用同一 CLI 认证通道进行有界只读对象定义检查；事件目录与旧版例程读取失败也会分类。仅固定权限错误码判定无权限；网络、对象不可见、版本差异或超过检查上限保持未确认。已确认无权限的对象类型禁用，已勾选类型必须显式取消，不能自动少导出；执行保留真实目标预检与确认。检查不等于完整导出或目标写入权限验收。

选择区域采用“对象类型 → 对象名称”的两级勾选布局，表、视图、触发器、例程及事件层级一致，全对象筛选只改变可见项。筛选期间匹配分类自动展开，清空后保留折叠和选择。仍保留权限禁用与驱动按类型选择的限制；不支持逐项选择的对象通过分类勾选，不假装支持单项排除。
